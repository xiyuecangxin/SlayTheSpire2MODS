## 快速安装
1. 解压本压缩包到任意位置
2. 双击运行 `皮皮模组管理器.bat`
3. 选择 `1. 安装模组`
4. 按提示操作即可

## 手动安装
1. 找到杀戮尖塔2的安装目录（包含 `SlayTheSpire2.exe` 的文件夹）
2. 将 `Mods` 文件夹中每个模组文件夹里的文件复制到游戏 `mods/<模组名>/` 下
   - `DamageMeter_v1.9.1` 里的文件 → `mods/DamageMeter/`
   - `ModConfig_v0.2.0` 里的文件 → `mods/ModConfig/`
   - `ModConfig_v0.2.1` 里的文件 → `mods/ModConfig/`
   - `QuickLink_v0.7.0` 里的文件 → `mods/QuickLink/`
   - `QuickLink_v0.7.1` 里的文件 → `mods/QuickLink/`
   - `QuickLink_v0.7.2` 里的文件 → `mods/QuickLink/`
   - `QuickLink_v0.7.3` 里的文件 → `mods/QuickLink/`
   - `QuickLink_v0.8.0` 里的文件 → `mods/QuickLink/`
   - `QuickLink_v0.8.1` 里的文件 → `mods/QuickLink/`
   - `QuickLink_v0.8.2` 里的文件 → `mods/QuickLink/`
   - `QuickLink_v0.8.3` 里的文件 → `mods/QuickLink/`
   - `QuickLink_v0.9.0` 里的文件 → `mods/QuickLink/`
   - `RemoveMultiplayerPlayerLimit` 里的文件 → `mods/RemoveMultiplayerPlayerLimit/`
   - `Rewind_v0.21.3` 里的文件 → `mods/Rewind/`
   - `SpeedX_v0.9.14` 里的文件 → `mods/SpeedX/`
   - `SpeedX_v0.9.17` 里的文件 → `mods/SpeedX/`
   - 如果 `mods` 文件夹不存在，请手动创建
3. 启动游戏，首次会提示启用模组，选择"是"

## 卸载
- 使用脚本：选择 `2. 卸载模组`
- 手动：删除游戏 `mods` 文件夹下对应的模组文件夹

## 存档说明
- 模组存档和原版存档**完全分开**，互不影响
- 首次使用模组相当于新档，可用脚本的 `4. 存档管理` 复制原版进度
